# v2.4.1 cloud-first food library

This release moves the Smart Food System toward a cloud-first model.

Principles:
- Supabase is the source of truth when signed in.
- Browser storage is only an offline/cache queue, never the authoritative library.
- The app checks the user's cloud food library before Open Food Facts for barcode scans.
- User-confirmed nutrition overrides public database values on future scans.
- Changes made on one signed-in device appear on other devices after automatic refresh.
- Offline changes are queued locally and retried automatically when connectivity returns.

Database setup:
Run `supabase_food_library_v2.4.1.sql` once in the Supabase SQL Editor before relying on cross-device food-library sync.
