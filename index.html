What I've learned about Darren's diabetes

Only statements supported by repeated data or an agreed analysis rule belong here. Status can move up or down as new evidence arrives.
PROVEN REPEATEDLYTime in range has stayed well above the 70% goal across the recent review history.
Recent stored reviews are in the mid-to-high 80s.
LIKELY1:15 remains the best-supported working ICR.
Current clean meal data does not support a blanket move to 1:10. Continue collecting isolated meals before any change is considered with the diabetes team.
LIKELYHigh-fat meals are more likely to cause a delayed or extended rise.
Fat grams are especially useful because the difficult meals are not always explained by carbs alone.
LIKELYLate afternoon and evening are currently more challenging than the morning.
The latest hourly report shows more high readings later in the day.
ANALYSIS RULEFast-acting insulin in Dexcom with no matching app entry is treated as an estimated / best-guess dose.
Typical example: restaurant food with no nutritional information. It is included in the overall picture but excluded from evidence for changing ICR.
ANALYSIS RULESuspected sensor errors are not allowed to distort conclusions.
Where a Dexcom low is clearly contradicted by a finger-prick and documented as faulty, it is treated as sensor error rather than a genuine hypo.
UNDER INVESTIGATIONWhich high-fat meals consistently need a different strategy?
Keep logging actual fat grams, meal type, timing and actual insulin so repeated patterns can earn a stronger evidence status.

3-file review protocol

Do not process a CGM review until all 3 files are present:
1. Dexcom Clarity PDF
2. Dexcom raw CSV
3. ICR Meal Dashboard CSV
If any file is missing, the review waits and a reminder is given before analysis starts. Once all 3 are present: analyse, compare, update this app, update the learned-insights page and send the review email.
